Project Report: AI-Powered Plant Disease Detection Platform

1. Introduction

Agriculture is the backbone of the global economy, yet crop diseases cause significant yield losses every year. Early and accurate detection of plant diseases is critical for farmers to take timely preventive measures. Traditional methods of disease identification rely on manual inspection by agricultural experts, which is time-consuming, expensive, and prone to human error. This project introduces a Full-Stack AI-Powered Plant Disease Detection Platform that utilizes deep learning (Convolutional Neural Networks) to automatically identify crop diseases from leaf images, providing instant diagnostics and tailored treatment recommendations.

2. Problem Statement

Farmers, especially in remote or developing regions, often lack immediate access to agricultural experts. When a crop begins exhibiting symptoms of a disease, the time taken to identify the pathogen and consult an expert can result in irreversible crop damage. Misdiagnosis further exacerbates the problem, leading to the incorrect application of pesticides, which harms the environment and increases farming costs. There is a critical need for an automated, accessible, and highly accurate system that can diagnose plant diseases instantly using just a smartphone or computer.

3. Objectives

The primary objectives of this project are:

  1. Automated Diagnosis: To develop a highly accurate Deep Learning model capable of classifying multiple plant diseases from leaf imagery.
  2. Actionable Solutions: To provide farmers with immediate, region-specific chemical, organic, and preventive treatment recommendations.
  3. Disease Progression Simulation: To implement a timeline simulator that forecasts how the disease will spread over 7, 14, and 30 days if left untreated.
  4. Accessibility: To build a robust, responsive, user-friendly web interface that can be easily accessed by users without technical expertise.
  5. Secure Ecosystem: To implement a secure authentication system (JWT) allowing users to maintain a private history of their diagnostics.

4. Existing System and Its Limitations

Existing System

Current solutions typically involve basic mobile applications that rely on standard rule-based algorithms or simple cloud-based API calls to generic third-party servers. Alternatively, farmers rely on government agricultural extension workers or local pesticide vendors for visual diagnosis.

Limitations

  • Latency & Dependency: Most existing automated systems require a constant, high-speed internet connection to send data to heavy cloud servers.
  • Lack of Comprehensive Treatment: Many apps only provide the name of the disease without offering detailed organic and chemical treatment plans.
  • No Progression Analysis: Existing systems do not simulate or warn the farmer about the potential future impact of the disease.
  • Poor UI/UX: Existing agricultural portals are often outdated, clunky, and not optimized for modern devices.

5. Proposed System

The proposed system is a completely integrated Full-Stack Application featuring an embedded Artificial Intelligence engine. Instead of relying on third-party APIs, the system utilizes a custom-trained MobileNetV2 Convolutional Neural Network (CNN) running natively on the FastAPI backend. Users can securely register, log in, and upload images of infected leaves. The system instantly processes the image, runs it through the neural network, and returns a confidence score alongside a curated database of organic/chemical treatments. Furthermore, a unique Disease Simulator calculates and visually renders the expected progression of the disease over a 30-day timeline.

6. Technology Stack

The platform is built using modern, industry-standard frameworks to ensure scalability, security, and performance.

  • Artificial Intelligence / Machine Learning:
    • TensorFlow / Keras (MobileNetV2 Architecture)
    • NumPy, Pillow (Image Processing)
  • Backend Framework:
    • Python 3.x
    • FastAPI (High-performance asynchronous API framework)
    • Uvicorn (ASGI Server)
  • Database & Security:
    • SQLite (Relational Database via SQLAlchemy ORM)
    • Passlib & Bcrypt (Password Hashing)
    • JSON Web Tokens (JWT) for secure session management
  • Frontend Technologies:
    • HTML5 / CSS3 (Responsive, Glassmorphism-inspired UI)
    • Vanilla JavaScript (ES6+) for dynamic DOM manipulation and asynchronous API fetching.

7. Implementation

7.1 Data Collection & Preprocessing

The model was trained on the renowned PlantVillage dataset, focusing heavily on Tomato and Pepper plant diseases. Data augmentation techniques (random flips and rotations) were applied to ensure the model generalizes well to real-world photos.

7.2 Model Architecture (MobileNetV2)

A Transfer Learning approach was used. The base architecture is MobileNetV2 (pre-trained on ImageNet), known for its lightweight footprint and high efficiency. A Global Average Pooling layer and a Dense output layer with softmax activation were added to classify the 15 specific disease classes.

7.3 Backend Architecture (FastAPI)

The backend is structured using a modular router approach (auth_routes.py, simulator_routes.py, routes.py). The inference engine intercepts uploaded images, converts them into numeric tensors, and passes them to the .keras model. Custom logic maps the model's mathematical output to a local database of treatment protocols.

7.4 Frontend Integration

The frontend operates as a Single Page Application (SPA). script.js handles secure token storage in localStorage, manages the visual transitions between the "Upload" and "Results" screens, and dynamically injects the AI's diagnostic text and the CSS-driven simulation timeline into the DOM.

8. Results

  • Model Accuracy: The AI model achieved a validation accuracy of 89.2% during training, demonstrating highly reliable classification across 15 distinct disease classes.
  • Inference Speed: The lightweight nature of MobileNetV2 allows the backend to process an image and return a response in less than 500 milliseconds.
  • System Stability: The FastAPI backend successfully handles concurrent user sessions, securely validating JWT tokens for every diagnostic request. The fallback mechanisms ensure the server never crashes, even if the ML model is temporarily unavailable.

9. Conclusion

The AI-Powered Plant Disease Detection Platform successfully bridges the gap between advanced deep learning and practical agriculture. By combining a highly accurate neural network with a fast, secure, and intuitive web application, the system empowers farmers to diagnose crop diseases instantly. The inclusion of actionable treatment data and a progression simulator elevates the platform from a simple diagnostic tool to a comprehensive agricultural advisory system. Future scopes include expanding the dataset to cover more regional crops and deploying the system to scalable cloud infrastructure like AWS or Heroku.
